# CS-320-Portfolio

To ensure that code is both functional and secure, I would use the strategies of Requirment based testing as well combined with Boundary Value Analysis. Functinoality is verified by creating a comprehensive suite of JUnit tests that exercise every path of logic. Implementing strict input validation at the object level to ensure that no null or improperly formatted data can enter system, which is importnat for security and data integrity. Interpreting user needs invloves breaking down high-level requirements into immeasurable, technical contraints. by asserting that the software must throw an IllegalArgumentException when business rules are violated, it was ensured that the program's behavior is aligned with the customer's expectations. 

My approach to designing software is rooted modularly and in the separation of concerns. Designing by separating the data objects from service logic that manages them. This can allow for a more organized code readability and where the boject can handle its own validation logic, while also the services handles the collection and unique ID generation. During the design phase, I prioritize testability by utilizing tools like @BeforeEach to set up clean test environments and ensuring code is efficient and non-redundant, I create a sustainable architecture that can be easily maintained and expanded without accumulating technical debt.
