Category III

Artifact Narrative: Databases & Data Security

Artifact Description

The artifact selected for this category is the persistent data layer of the Travlr Getaways application, built with MongoDB, Express.js, and Node.js. It powers a full-stack architecture that serves dynamic customer travel data while providing an authenticated administrative dashboard for record management.

Justification of Inclusion

This artifact demonstrates competence in non-relational document modeling, persistent storage operations, and robust database authorization. The initial iteration contained unauthenticated CRUD operations and loose schema constraints that left endpoints susceptible to injection attacks and inconsistent data states.

Key enhancements made to the system:

  • Normalized Mongoose Schemas: Implemented strict validation constraints, field type casting, and default handlers to guarantee data integrity across document collections.
  • Stateless Authentication (JWT): Integrated JSON Web Token (JWT) verification middleware alongside salted password hashing (bcrypt) to enforce strict access control on all modification endpoints.
  • Query Optimization & Sanitization: Added targeted indexing on frequently searched fields and sanitized incoming query payloads to defend against NoSQL injection vectors.

Course Outcomes Met

  • Outcome 4 (Data Persistence & Security): Implemented secure data storage solutions utilizing role-based access control, cryptographic password storage, and structured query handling.
  • Outcome 5 (Full-Stack System Integration): Connected decoupled client interfaces to persistent backend services through RESTful endpoints while maintaining separation of concerns.

Reflection & Evolution

Developing and refactoring this persistent service bridged the gap between front-end UI interactions and backend reliability. It illustrated that database architecture cannot be isolated from application security—every access vector must be guarded by strict validation, parameterized lookups, and explicit authentication controls.
