Artifact Narrative: Software Design & Engineering

Artifact Description

The artifact selected for this category is the Contact Service architecture, initially developed in Java during intermediate coursework. The system functions as a domain service layer managing contact records, unique identifiers, personal contact attributes, and CRUD operations within an in-memory data store.

Justification of Inclusion

This artifact demonstrates proficiency in object-oriented design patterns, defensive programming, and decoupled software architecture. Prior to enhancement, the codebase exhibited tight coupling, mutable internal state, and brittle parameter handling.

Course Outcomes Met

  • Outcome 1 (Design & Architecture): Applied modular decomposition and clean architectural boundaries.
  • Outcome 3 (Defensive Programming): Enforced boundary checks, parameter validation, and comprehensive JUnit test coverage.

Reflection & Evolution

Revisiting this artifact highlighted the difference between code that simply passes basic functional tests and software engineered for maintainability and extensibility.
